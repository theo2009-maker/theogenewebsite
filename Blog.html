What I am learning

Short notes in simple language. Click a post to read it.

A bootloader is the first small program that runs when you switch on a computer. On old-style PCs it lives in the first 512 bytes of the disk. It loads the kernel into memory and then gives control to it.

The kernel is the heart of an operating system. It talks to the hardware, manages memory and decides which program runs and when.

QEMU pretends to be a computer inside your computer. You can test your kernel safely there, without risking your real machine.

I read a small part, type the code myself, run it, and only then move on. Small steps every day beat a long study once a week.
